# CD3 sampling animation design package

This package specifies animations; it does not contain an animation application.

Read `docs/superpowers/specs/2026-10-20-sampling-animations-design.md` for the complete model definitions, example-to-method map, scene storyboards, correct NS/INS distinction, Nautilus regression explanation, interaction contract, implementation boundaries, and validation requirements.

Read `research/research-notes.md` for the rationale and research limitations. `research/reference_checks.json` contains independently calculated analytic/quadrature values for the proposed toy problems. They are not sampler benchmark results.

The primary route lasts 20 minutes, with a separate 25-minute route. The recommended next stage is review of the written design, followed by a repository-specific implementation plan.
